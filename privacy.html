Privacy Policy

This policy covers two things: this website, and the Fieldnote Zero Studio Tool, a private application that uses Google's YouTube APIs to manage the Fieldnote Zero YouTube channel (@fieldnotezerohq).

1. Who uses the Studio Tool

The Studio Tool is used only by the owner of the Fieldnote Zero channel, on the owner's own computer. It is not offered to the public, and it does not sign in, collect data from, or act for any other person or channel. Before any change, it checks that the authorized channel is Fieldnote Zero and refuses to act on any other channel.

2. Google user data the Studio Tool accesses

When the channel owner signs in with Google, the owner grants these permissions (OAuth scopes):

ScopeWhat the tool does with it
youtubeReads the channel's identity (channel ID, title, handle), public statistics, upload list and video status; sets thumbnails; updates the channel's banner, description and watermark; deletes the owner's own test uploads when asked.
youtube.uploadUploads the channel's own videos, always as private first.
yt-analytics.readonlyReads channel and video performance reports (for example views, watch time, average view duration, audience retention, subscribers gained and lost).

The tool does not request access to Gmail, Drive, contacts, comments from viewers, or revenue data. It does not access the personal data of viewers; YouTube Analytics reports are aggregated statistics.

3. How the data is used

  • To publish and manage the channel's own videos and branding, at the owner's direction.
  • To review the channel's performance and improve future episodes.

The data is not sold, rented, used for advertising, or used to train general-purpose AI models. It is not shared with anyone except as described in section 4.

4. Who can see it

  • Google / YouTube, which provide the APIs.
  • The owner's AI assistant. The owner operates the tool with help from an AI assistant (Anthropic's Claude). Command results, such as channel statistics and analytics figures, can be seen by that assistant while it works for the owner. OAuth tokens and client secrets are never shown to it in output.

No other third parties receive Google user data.

5. Storage and security

  • OAuth credentials (the client file and refresh token) are stored only on the owner's computer, in a folder readable only by the owner's Windows account. They are never placed in code repositories, notes, or this website.
  • Analytics results and upload records are stored in the owner's local project files.
  • All API traffic uses HTTPS. If storage ever moves to a cloud service (for example encrypted repository secrets for scheduled jobs), this policy will be updated first.

6. Retention and deletion

  • The refresh token is kept until the owner revokes it or the tool is retired, then deleted.
  • Analytics records are kept for as long as they are useful for running the channel, and can be deleted at any time.
  • To revoke access at any time, remove "Fieldnote Zero" at myaccount.google.com/permissions. Revoking stops all access immediately; the local token is then deleted.

7. Google and YouTube policies

The Studio Tool uses YouTube API Services. By using it, the account holder is bound by the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

The Studio Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. This website

This is a static website. It sets no cookies, runs no analytics or advertising, and has no forms. It is hosted on GitHub Pages; GitHub may log technical request data such as IP addresses for security, as described in the GitHub Privacy Statement.

9. Changes and contact

Changes to this policy are published on this page with a new effective date. Questions or requests: open an issue at github.com/ruyima1/fieldnote-zero/issues.
